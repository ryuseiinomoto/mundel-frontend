WHY I BUILT THIS

大学で学んだ理論を、
根拠のあるトレードに変えたかった。

大学でマクロ経済学を学ぶ中で、FX初心者が陥りやすい問題に気づきました。

  • 01根拠のないトレードで損失を出す
  • 02情報商材に頼り、経済の仕組みを理解しないまま売買する
  • 03経済ニュースが為替にどう影響するかがわからない

IS-LM-BPモデルは、金利・為替・所得の相互関係を一つの図で説明できる強力なフレームワークです。 「これを理論で終わらせるのは惜しい」——FXトレードの予習ツールとして使えないかと考えたのが、mundel の出発点でした。

スキャルピングではなく、スイング・ポジショントレードに必要なマクロ経済の読み方を、 実際のニュースを通じて鍛える。情報商材に頼らず、経済の仕組みから根拠を持てる人を増やしたい——そんな思いで開発しています。

HOW IT WORKS

ニュースから、根拠ある一手まで。

経済ニュースを入力するだけで、理論にもとづいた解析とシグナルが返ってきます。

01

ニュースを入力

経済ニュースを入力すると、AI（Gemini）が IS・LM・BP の各曲線がどう動くかを解析します。

02

グラフで確認

IS-LM-BPモデルのグラフがリアルタイムでシフト。経済の変化を視覚的に理解できます。

03

AIシグナル

BUY / SELL / HOLD のシグナルと、その根拠を日本語で解説。判断のプロセスごと学べます。

04

模擬トレード

分析した根拠をもとに模擬トレードを実践。損益で自分の理解度を確認できます。

FX BEGINNER COURSE

為替の基礎から IS-LM-BP まで、11ステップで体系的に。

各ステップのクイズに正解するとクリア。最後は模擬トレードで実践し、根拠を持って相場を読む力を身につけます。

TECH STACK & ARCHITECTURE

理論を、動くプロダクトに。

Frontend

  • Next.js App Router / TypeScript
  • Tailwind CSS
  • Framer Motion アニメーション
  • Recharts IS-LM-BPグラフ描画
  • i18next 日 / English / 中文

Backend

  • FastAPI Python
  • Gemini API ニュースのマクロ解析
  • NewsAPI FX関連ニュース

  • Google Cloud Run フロント / バックエンド

  • Server-side proxy APIキー保護
